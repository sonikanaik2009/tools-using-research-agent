# Tool-using Research Agent

An AI-powered research agent that searches the web, analyzes relevant sources, and generates source-grounded answers with citations.

The application uses **Tavily** for web search, **Google Gemini** for answer generation, and **Streamlit** for the user interface.

## Features

- Accepts research questions through a web interface.
- Searches the web using Tavily.
- Retrieves relevant web sources and their content.
- Uses Google Gemini to synthesize information from the retrieved sources.
- Generates answers grounded in web research.
- Provides numbered citations such as `[1]`, `[2]`, and `[3]`.
- Displays the original source titles and clickable URLs.
- Handles empty queries and API failures.
- Includes retry logic for temporary AI service failures.

## How It Works

1. The user enters a research question in the Streamlit interface.
2. `app.py` sends the question to the research agent.
3. `agent.py` calls the web search function in `search_tool.py`.
4. Tavily searches the web and returns relevant sources.
5. Each source is assigned a numbered ID.
6. The retrieved source content is provided to Google Gemini as research context.
7. Gemini generates an answer using the provided sources and cites them using their numbered IDs.
8. Streamlit displays the generated answer along with the original clickable source links.

### File Responsibilities

**`app.py`**

Contains the Streamlit user interface. It collects the research question and displays the generated answer and sources.

**`agent.py`**

Contains the main research-agent logic. It combines Tavily search results with Gemini to produce a source-grounded answer.

**`search_tool.py`**

Contains the Tavily search functionality and converts search results into structured source information.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/sonikanaik2009/tools-using-research-agent.git
```

Move into the project directory:

```bash
cd tools-using-research-agent
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

On Windows, activate it using:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## API Key Setup

The project requires:

- Tavily API key
- Google Gemini API key

Create a `.env` file in the project root.

You can copy the structure from `.env.example`:

```env
TAVILY_API_KEY=your_tavily_api_key
GEMINI_API_KEY=your_gemini_api_key
```

Never commit your `.env` file or API keys to GitHub.

## Running the Application

Make sure the virtual environment is activated, then run:

```bash
streamlit run app.py
```

Streamlit will start the application and provide a local URL, usually:

```text
http://localhost:8501
```

Open it in your browser and enter a research question.

## Citation Approach

Tavily provides the original web sources and URLs.

The application assigns each retrieved source a number:

```text
[1]
[2]
[3]
...
```

Gemini receives the numbered source content and is instructed to cite factual claims using those source numbers.

The actual URLs are retained by the Python application rather than generated by the language model. This reduces the risk of fabricated source URLs.

## Error Handling

The application handles common failures such as:

- Missing API keys
- Web search failures
- No search results
- Temporary Gemini API failures
- Empty user questions

Temporary Gemini failures are retried before an error is shown to the user.
